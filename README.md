# PunchBass - kick & bass enhancer (VST3, JUCE 7)

PUNCH: transient shaper (Punch = attack boost, Tail = sustain up/down)
FAT: split @ Split Hz, low band tanh saturation (Drive, Warmth = even harmonics, Fat = amount)
WEIGHT: sub-region peak boost (gain + frequency)
OUTPUT: Mix (parallel), Output gain, safety limiter, Mono Bass switch.

Build: push this folder to a GitHub repo -> Actions -> artifact PunchBass-VST3-windows.
Copy PunchBass.vst3 to C:\Program Files\Common Files\VST3
